# 📈 Linear Regression & Regression Metrics

A beginner-friendly Machine Learning project demonstrating **Simple
Linear Regression** using Scikit-Learn. This notebook predicts
**Salary** based on **Years of Experience** and evaluates the model
using common regression metrics.

------------------------------------------------------------------------

## 🚀 Project Overview

The objective of this project is to understand how Linear Regression
works by:

-   Creating a custom salary dataset
-   Visualizing the relationship between experience and salary
-   Training a Linear Regression model
-   Predicting salaries for unseen data
-   Evaluating model performance using regression metrics

## 📂 Dataset

  Feature              Description
  -------------------- ------------------------------------
  Experience (Years)   Number of years of work experience
  Salary               Annual salary

## 🛠️ Technologies Used

-   Python
-   NumPy
-   Pandas
-   Matplotlib
-   Scikit-Learn

## 📊 Workflow

1.  Import libraries
2.  Create dataset
3.  Visualize data
4.  Train-test split
5.  Train Linear Regression model
6.  Plot Best Fit Line
7.  Make predictions
8.  Evaluate using MSE, RMSE, MAE and R² Score

## 📐 Regression Metrics

-   **MSE** -- Mean Squared Error
-   **RMSE** -- Root Mean Squared Error
-   **MAE** -- Mean Absolute Error
-   **R² Score** -- Coefficient of Determination

## 🎯 Learning Outcomes

-   Understand Linear Regression
-   Train and evaluate a regression model
-   Visualize regression results
-   Interpret regression metrics
